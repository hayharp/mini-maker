# Mini Maker
This is a plug-in for GIMP 3.2 that converts Printable Heroes paper miniature files into a format that can be imported into cutting machine software.
It is primarily intended for generating files for printing (and cutting) double-sided miniatures; it outputs PNGs of minis packed into sheets.
It is also somewhat compatible with Paper Forge minis, and should be compatible with other makers as well who use a similar fold-line pattern.


## Installation
This plug-in has only been tested on Linux. Clone the mini-maker directory into your GIMP plug-in folder.
Run `chmod +x mini-maker.py` in the directory to allow GIMP to run the plug-in.

This plug-in relies upon [Batcher](https://kamilburda.github.io/batcher/) to export layers; check out their project site for installation instructions.

## Usage
#### Generate your front and back layers
1. Import your desired mini as a PNG into GIMP
2. Navigate to Image > Mini Maker
3. Edit Name, Mini Size, and Scale as desired
4. Border Width can be modified as a matter of preference. At 300 DPI, 8 is a safe bet for 25mm, 10 for 50mm, and 12 for 75mm
5. Fold Line Direction must be set to whatever direction the file's center line runs
6. Left Border Buffer can normally be left at the default; increase it if the bounding box lines are very thick for your file
7. Click "OK" and wait while the Mini Maker does its thing!
8. Export the Front Cut and Back Cut layers

#### Generate a sheet of minis for your cutting machine
1. Create a new project
2. Import the **front artwork** of your desired minis, as generated by the Mini Maker procedure
3. Navigate to Image > Mini Sheet Maker
4. Set the filepath where your artwork lives (they must all inhabit the same filepath)
5. Set the artwork DPI (must be consistent across minis)
6. "Art Buffer" controls the space between minis on the page. "Alignment Buffer" controls the space in mm between the edge of the paper and where the minis start
7. "Fill Art Whitespace" generates a layer of black behind each piece of artwork so that whitespace not caught by the cutting machine is filled with black
8. Click "OK"
9. Adjust how many of each mini you want, click "OK", and wait while the Mini Sheet Maker does it thing!
10. Export the output layers

## Limitations
**Floating minis** do not work out of the box, as there's no algorithmic way to identify where the bottom edge of the mini should be.
Drawing in a black connector to the edges of the half-circles is an easy solution to this.

**Upscaling** is not currently automated. You can manually upscale a mini before running the Mini Maker plug-in.

**Non-standard formats** (without the normal fold line patterns and bottom half-circle) are not supported.

## Contributions
If you wish to contribute, please submit an issue or a pull request!
There are lots of edge-case minis from Printable Heroes that can cause this plug-in to get confused--please submit an issue if you find one.

This project was made without the use of AI.
Out of respect for the artistic, hobbyist, and creative communities involved in the creation of paper miniatures, AI-aided contributions are not welcome.
